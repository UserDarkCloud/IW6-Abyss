# IW6x Mod

## Requirements

- Call Of Duty Ghosts IW6x installed and working
- Launched at least once so the folders exist
- WinRAR or 7-Zip, for your download

## Installation

1. Download `AbyssIW6x`
2. Go To Folder Containing IW6x
3. Go to `ghosts_game_files` → Replace `data` Folder
4. Launch IW6x and start an Extinction game.

## Controls

| Action | Controller Bind |
|---|---|
| Open Menu | Hold ADS + E |
| Scroll Up | ADS |
| Scroll Down | Fire |
| Select | F |
| Back / Close | E |
| Value Down | G |
